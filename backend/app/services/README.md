# Business-logic services (per spec section 8.3)

Planned services — none implemented yet:

- `identity.py` — auth, RBAC enforcement, audit log
- `restaurant_service.py` — locations, hours, menus, price sync
- `order_service.py` — lifecycle, payment state, cancellation, refund
- `dispatch_service.py` — serviceability, matching, batching, sequencing, ETA
- `delivery_service.py` — pickup/drop-off verification, proof of delivery
- `payments_service.py` — payment abstraction, ledger, settlements
- `analytics_service.py` — pilot metrics (spec section 12)
- `notifications_service.py` — order-status notifications
- `maps.py` — maps provider abstraction (Google Maps / Mapbox)
